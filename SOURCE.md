# Corresponding source

Each binary release includes a `zynamfx-source-<version>.tar.gz` archive containing the matching application source, build scripts, exact JUCE source with the local patch, NAM, AudioDSPTools, and vendored dependencies. The archive excludes user settings, credentials, and downloaded catalog models.

The archive is generated by `script/package-local-source.py` from the exact release commit and verifies every included file against a SHA-256 manifest. Build it after committing source:

```sh
python3 script/package-local-source.py dist/zynamfx-source-2.0.0.tar.gz
```

The public Version 2 repository is <https://github.com/zackyusof/zynamfx>. Its Version 1 predecessor is archived privately. For a local macOS build, initialize submodules and run `python3 script/build-stadium-prototype.py`. The public release workflow builds Standalone, AU, and VST3 with an empty TONE3000 publishable key and includes the corresponding-source archive with the binaries.
